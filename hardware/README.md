# Аппаратная часть

Симуляция в Wokwi: https://wokwi.com/projects/471774380925745153

Схема из файла [`diagram.json`](../diagram.json) открывается непосредственно
в [Wokwi](https://wokwi.com/) либо в расширении Wokwi для VS Code.

## Перечень элементов

| Кол-во | Элемент | Примечание |
|-------:|---------|------------|
| 1 | Arduino Nano | допустима замена на Uno |
| 1 | Модуль реле | срабатывание по низкому уровню (`RELAY_LOW 1` в `config.h`) |
| 1 | ИК-приёмник | VS1838B или совместимый, 38 кГц |
| 1 | Микрофонный модуль | с цифровым выходом |
| 1 | Пассивный зуммер | управляется функцией `tone()` |
| 1 | Светодиод + резистор 220 Ом | индикация состояния |
| 4 | Тактовая кнопка | замыкание на землю, внутренние подтяжки |

## Назначение выводов

| Вывод | Сигнал | Направление | Примечание |
|------:|--------|-------------|------------|
| D2  | Данные ИК-приёмника | вход | |
| D3  | Выход микрофона | вход | `INPUT_PULLUP`; хлопок определяется по спадающему фронту |
| D4  | Управление реле | выход | низкий уровень — реле включено |
| D5  | Светодиод индикации | выход (ШИМ) | через резистор 220 Ом |
| D6  | Зуммер | выход | `tone()` |
| D7  | Кнопка — свет вкл/выкл | вход | `INPUT_PULLUP` |
| D8  | Кнопка — сброс всех таймеров | вход | `INPUT_PULLUP` |
| D9  | Кнопка — mute (отключение микрофона) | вход | `INPUT_PULLUP` |
| D10 | Кнопка — ночной режим | вход | `INPUT_PULLUP` |

## Особенности монтажа

- Все кнопки замыкают вывод на **землю**; внешние подтягивающие резисторы
  не требуются — скетч включает внутренние.
- Модуль реле питается от отдельного источника **12 В, 2 А**. **Земля модуля
  должна быть объединена с землёй Arduino.**
- Реле размыкает **фазный провод** лампы 220 В, но не нулевой.
- В симуляции Wokwi микрофон замещён кнопкой на выводе D3.

> ⚠️ **Сетевое напряжение.** Монтаж стороны 220 В выполняйте только при наличии
> соответствующей квалификации и исключительно на обесточенной схеме.
