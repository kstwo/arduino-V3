# Светильник на Arduino

Управление лампой через реле: ИК-пульт, двойной хлопок, таймеры отключения и четыре кнопки на корпусе.

## Что умеет

- Включение и выключение света с пульта.
- Двойной хлопок переключает свет.
- Таймер отключения от одной минуты до восьми часов — кнопками на пульте.
- Четыре кнопки на корпусе: свет, сброс таймеров, mute, ночной режим.
- В ночном режиме зуммер и светодиод молчат, чтобы не мешать спать.

## Железо

Arduino Nano (подойдёт и Uno), модуль реле со срабатыванием по низкому уровню, ИК-приёмник VS1838B, микрофонный модуль с цифровым выходом, пассивный зуммер, светодиод с резистором на 220 Ом и четыре кнопки.

Перечень элементов, назначение выводов и особенности монтажа — в [`hardware/README.md`](hardware/README.md).

## Сборка и прошивка

Версии ядра и библиотек зафиксированы в `sketch.yaml`, поэтому ставить IRremote вручную не нужно: arduino-cli подтянет нужный релиз при первой сборке.

```bash
arduino-cli compile --profile nano
arduino-cli board list
arduino-cli upload --profile nano -p /dev/cu.usbserial-1410
```

Профиль `nano_old_bootloader` — для дешёвых клонов Nano, которые не прошиваются обычным профилем. Профиль `uno` — для Uno.

Посмотреть вывод платы:

```bash
arduino-cli monitor --profile nano -p /dev/cu.usbserial-1410 -c baudrate=115200
```

### Arduino IDE

Откройте `arduinov3.ino` в корне репозитория. Каталог репозитория должен называться `arduinov3`, иначе IDE предложит переименовать скетч. Библиотеку IRremote версии 4.x в этом случае придётся поставить через менеджер библиотек: `sketch.yaml` понимает только arduino-cli.

### Свой пульт

Коды команд, пины и тайминги собраны в [`src/config.h`](src/config.h). Если пульт другой, снимите его коды примером `ReceiveDemo` из IRremote и замените константы `IR_*`. Разные пульты дают разные коды — с этого стоит начинать, если что-то не работает.

## Проверка без платы

Схема и настройки симулятора лежат в корне: `diagram.json` и `wokwi.toml`. Соберите прошивку, затем запустите симуляцию расширением Wokwi в VS Code либо откройте проект по ссылке из [`hardware/README.md`](hardware/README.md).

```bash
arduino-cli compile --profile nano --output-dir build/arduino.avr.nano
```

Микрофона в симуляции нет: его заменяет кнопка на выводе D3.

## Тесты

Логика прошивки не обращается к Arduino напрямую, поэтому собирается и проверяется на компьютере.

```bash
cmake -S test -B test/build
cmake --build test/build
ctest --test-dir test/build --output-on-failure
```

Проверка эквивалентности прогоняет прежнюю версию прошивки рядом с текущей на одном потоке входов и сравнивает уровни реле, светодиода и зуммера на каждом шаге.

## Структура

| Путь | Что внутри |
|------|------------|
| `arduinov3.ino` | слой железа: чтение выводов, вызов логики, запись результата |
| `src/` | логика: кнопки, хлопки, таймер, мелодии, индикация |
| `src/config.h` | пины, тайминги, коды пульта |
| `test/` | проверка логики на компьютере |
| `hardware/` | схема, перечень элементов, монтаж |

## Нюансы

- После щелчка реле микрофон глохнет на полсекунды, иначе ловит свой же щелчок.
- В режиме mute микрофон не слушает вовсе.
- Watchdog перезагрузит плату, если та зависнет. На практике не пригодился ни разу.
